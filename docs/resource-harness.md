# Resource harness

The opt-in [resource harness](../contrib/resource-harness/README.md) adds ten shared
API slots, ten delegated-agent slots, two browser-session owners, bounded waits,
cleanup, service resource limits and independent health recovery. It targets the
Hermes 0.22.2 runtime on Linux; the older fork containing this contribution is not
itself a supported runtime for the plugin.
